1. Follow the test protocol

Use non-beneficiary test records. Capture enough evidence that another owner can reproduce the result.

Run the full workflow

Start at the original source. Confirm the record, assignment, outreach, appointment, application, reporting, and service handoffs.

Document the evidence

Record timestamps, system IDs, screenshots, report locations, and the exact result. Do not enter beneficiary PII or PHI here.

Retest every fix

A planned fix does not close a failure. Assign an owner and date, then rerun the scenario and update the result.
